# ARM RESULTS（プロトタイプ）

アームレスリングの **大会成績・選手成績・対戦結果を動画付きで確認できる** サイトの原型です。
ビルド不要の HTML / CSS / JavaScript だけで動きます。

## 起動方法

`start.bat` をダブルクリック → ブラウザで http://localhost:8080/ が開きます。

- PowerShell で手動起動する場合: `powershell -ExecutionPolicy Bypass -File serve.ps1`
- `index.html` を直接開いても動きますが、YouTube 埋め込みは `file://` だと再生できないことがあるため、サーバー経由を推奨します。

## 画面構成（ハッシュルーティング）

| URL | 内容 |
| --- | --- |
| `#/` | ホーム：最新大会の優勝者、年間ランキング（右腕/左腕）、最近の試合、試合動画 |
| `#/tournaments` | 大会一覧 |
| `#/tournaments/:id?c=階級&arm=R\|L` | 大会詳細：階級・腕ごとのトーナメント表、最終順位、試合結果 |
| `#/athletes` | 選手一覧（名前・チーム・都道府県で検索、階級で絞り込み） |
| `#/athletes/:id` | 選手詳細：通算成績、勝率、優勝・メダル数、連勝、腕別成績、対戦相手別成績、大会成績、試合履歴 |
| `#/matches` | 試合一覧（大会・階級・腕・動画有無で絞り込み） |
| `#/matches/:id` | 試合詳細：動画プレーヤー、勝敗・決着方法・時間、2人の対戦成績、同ブロックの試合 |
| `#/h2h?a=:id&b=:id` | 対戦比較：直接対決の成績と通算スタッツの比較 |

## ファイル構成

```
index.html      レイアウト（ヘッダー/フッター）
css/style.css   スタイル（ライト/ダーク両対応・レスポンシブ）
js/data.js      サンプルデータ（架空の選手・大会）
js/store.js     データアクセス層（集計・ランキング・対戦成績など）
js/app.js       画面描画とルーター
serve.ps1       ローカル確認用の簡易サーバー
```

## 動画の登録

1. 試合詳細ページの「動画を登録する」から YouTube の URL（または mp4 の URL）と開始位置を入力
2. 登録した内容はこのブラウザ（localStorage）に保存されます
3. フッターの「登録動画をエクスポート」で `videos.json` を出力し、中身を `js/data.js` の `videos` に貼り付けると、全員に反映されます

## データの追加

`js/data.js` の `tournaments[].results` に、階級・腕ごとの順位（1位〜4位）を書くと、
準決勝・3位決定戦・決勝の試合が自動で作られます（プロトタイプ用の簡易形式）。
決着方法と試合時間は、試合IDから決まるダミー値です。

## 本番化に向けた次のステップ（案）

- **データベース + API**：選手・大会・試合・動画をテーブル化し、`js/store.js` の中身を API 呼び出しに置き換える（画面側はほぼそのまま使える設計）
- **試合データを実際の記録形式に**：任意人数のトーナメント（ダブルエリミネーション含む）、ラウンド数、ファウル数、審判メモなど
- **管理画面**：大会結果の入力、動画の登録・承認（ログイン付き）
- **選手写真・大会ロゴ**などの画像アップロード
- **SEO**：選手・試合ごとの個別URLをサーバー側で描画（Next.js などへの移行を検討）
